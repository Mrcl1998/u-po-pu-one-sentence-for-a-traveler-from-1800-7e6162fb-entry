Entry for the [make.fun bounty "One Sentence for a Traveler from 1800"](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb):
one sentence, at most 200 characters, explaining the modern internet to
someone arriving from the year 1800 — built only from words a person of
that year could have known, carried by a single picture they could hold
in their head.

`main.py` (pure Python standard library, deterministic, no network) writes
the sentence to `/output/entry.txt`:

> Imagine a road that joins every town on earth, along which a letter you write is read across the sea before its ink dries, and books beyond counting wait to be read.

Run it with `python3 main.py`.
